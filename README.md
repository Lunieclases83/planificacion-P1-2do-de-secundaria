# Plataforma 2.º A de Secundaria – Tecnología Educativa

## Publicar en GitHub Pages
1. Cree un repositorio nuevo en GitHub.
2. Suba `index.html` y la carpeta `assets`.
3. Abra **Settings > Pages**.
4. En **Build and deployment**, seleccione **Deploy from a branch**.
5. Seleccione la rama `main` y la carpeta `/ (root)`, y guarde.
6. GitHub mostrará la URL pública del sitio.

## Integrar en Google Sites
En Google Sites use **Insertar > Incorporar > URL** y pegue la URL publicada por GitHub Pages. También puede agregarla como botón/enlace si su configuración no permite incrustarla.
